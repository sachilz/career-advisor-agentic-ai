## About the Role

CUBE is hiring a **Senior Platform Engineer** to join the Cloud
Engineering team. The role focuses on cloud strategy, SecDevOps,
platform engineering, and modernization initiatives while collaborating
with Engineering, Security, Infrastructure, and Product teams.

## Key Responsibilities

-   Design, build, and operate cloud platforms.
-   Manage Microsoft Azure infrastructure and Landing Zones.
-   Deploy containerized applications using Docker and Kubernetes.
-   Build Infrastructure as Code (Terraform).
-   Maintain CI/CD pipelines using Azure DevOps and GitHub.
-   Manage source code using Git.
-   Design Elasticsearch search and analytics solutions.
-   Automate tasks using Bash or PowerShell.
-   Develop tooling using Python or Golang.
-   Implement monitoring with Prometheus or New Relic.
-   Ensure security, reliability, compliance, and performance.
-   Handle incident response and root cause analysis.
-   Build reusable infrastructure modules.
-   Implement structured deployment and change control.
-   Maintain backup and disaster recovery processes.
-   Improve systems by reducing technical debt and bottlenecks.
-   Collaborate with Software Engineers, QA Engineers, and Platform
    Engineers.
-   Promote AI-assisted engineering tools (Claude Code, Cowork).
-   Mentor junior engineers.
