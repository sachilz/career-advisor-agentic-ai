## Roles and Responsibilities

* **AWS Cloud & Serverless:** Manage serverless architectures (ECS, Kubernetes, RDS, Lambda, Beanstalk, etc.) and regular services like VPC, EC2, and Storage.
* **CI/CD Pipelines:** Implement and manage CI/CD pipelines using tools like Azure DevOps, GitHub Actions, or Jenkins (experience with any helps).
* **Infrastructure as Code (IaC):** Automate infrastructure provisioning using tools like Terraform.
* **Containerization:** Implement and maintain Docker containerization and orchestrate applications using Azure Kubernetes Service (AKS).
* **Observability:** Ensure mandatory monitoring using CloudWatch, Azure Monitor, or general multi-cloud experience.
* **Security:** Implement security best practices across cloud environments.
* **Optimization:** Optimize cloud resources for performance and cost efficiency, ensuring scalability through auto-scaling features.
* **Collaboration:** Collaborate with cross-functional teams to troubleshoot and resolve pipeline and infrastructure issues.

## Qualifications

* **5+ years** of strong knowledge of AWS.
* Ability to learn new requirements quickly at a rapid pace.
* Mandatory scripting skills in **Bash, YAML, or Python**.
* Hands-on experience with Infrastructure as Code (IaC) using **Terraform**.
* Moderate hands-on experience with **Docker and Kubernetes** for container orchestration.
* Proficiency in monitoring and logging tools.
