# Job Description: Associate / Software Engineer (Full Stack)

## Position Overview
We are looking for an Associate Software Engineer to join our core product engineering team. You will be responsible for designing and developing scalable web applications, RESTful microservices, and database schemas.

## Key Responsibilities
- Write clean, maintainable, and well-tested code in Python, Java, JavaScript, or TypeScript.
- Build responsive front-end user interfaces using React.js, Next.js, or Vue.js.
- Develop robust back-end APIs and services using Node.js/Express, Spring Boot, or Django/FastAPI.
- Write unit tests, integration tests, and participate in peer code reviews.
- Optimize database queries, schema design, and caching (PostgreSQL, Redis, MySQL).
- Participate in Agile/Scrum ceremonies including daily standups, sprint planning, and retrospectives.

## Minimum Qualifications & Requirements
- Bachelor's degree in Computer Science, Software Engineering, or equivalent IT degree.
- Solid understanding of Data Structures, Algorithms, Object-Oriented Programming (OOP), and Design Patterns.
- Hands-on experience with REST APIs, Git, JSON, and Web HTTP fundamentals.
- Basic knowledge of containerization with Docker and cloud hosting services.
- Excellent analytical problem-solving skills and communication abilities.
