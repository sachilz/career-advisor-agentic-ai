# Job Description: DevOps & Infrastructure Engineer

## Position Overview
We are looking for a skilled DevOps Engineer to join our cloud infrastructure team in Colombo, Sri Lanka. In this role, you will build, maintain, and optimize robust CI/CD pipelines, automate cloud provisioning, and ensure high availability, scalability, and security for our software applications.

## Key Responsibilities
- Design, implement, and maintain CI/CD pipelines using GitHub Actions, GitLab CI, or Jenkins.
- Infrastructure as Code (IaC) provisioning using Terraform, CloudFormation, and Ansible.
- Containerization and orchestration of microservices using Docker and Kubernetes (EKS/AKS).
- Cloud administration across AWS (EC2, S3, RDS, IAM, VPC) or Microsoft Azure.
- Implement system monitoring, logging, and alerting using Prometheus, Grafana, and ELK stack.
- Collaborate with software developers to streamline release management and maintain zero-downtime deployments.

## Minimum Required Qualifications & Skills
- Bachelor's degree in Computer Science, Software Engineering, or Information Technology.
- Proficiency in Linux administration, Shell scripting, and Python or Go.
- Hands-on experience with Docker, Kubernetes, and container security best practices.
- Core knowledge of cloud platforms (AWS Certified Solutions Architect or SysOps Administrator preferred).
- Familiarity with Git version control, branch strategies, and GitOps workflows.
- Strong understanding of networking, DNS, TCP/IP, load balancers, and SSL/TLS configuration.

## Preferred Qualifications
- AWS Certified DevOps Engineer - Professional or CKA (Certified Kubernetes Administrator).
- Experience with infrastructure security (DevSecOps), secret management (HashiCorp Vault), and compliance monitoring.
