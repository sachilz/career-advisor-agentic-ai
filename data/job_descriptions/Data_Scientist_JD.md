# Job Description: Data Scientist / Machine Learning Engineer

## Position Overview
Our data science team is seeking an enthusiastic Data Scientist to develop statistical models, machine learning algorithms, and data pipelines to solve complex business problems.

## Key Responsibilities
- Collect, clean, and preprocess large unstructured and structured datasets from multiple data sources.
- Perform exploratory data analysis (EDA) to uncover trends, patterns, and insights.
- Build, train, evaluate, and fine-tune machine learning and deep learning models using Scikit-Learn, PyTorch, or TensorFlow.
- Deploy machine learning models into production REST APIs using FastAPI, Flask, or Docker.
- Develop data visualization dashboards using Streamlit, PowerBI, or Tableau.
- Collaborate with software engineers, product managers, and business stakeholders.

## Minimum Required Qualifications & Skills
- Bachelor's degree in Data Science, Computer Science, Mathematics, Statistics, or related technical field.
- Strong programming skills in Python (Pandas, NumPy, Scikit-Learn, SciPy) and SQL.
- Practical understanding of machine learning algorithms: Regression, Decision Trees, Random Forests, XGBoost, Clustering, and Neural Networks.
- Experience with database management systems (PostgreSQL, MongoDB, BigQuery).
- Understanding of model evaluation metrics (Precision, Recall, F1-Score, ROC-AUC, RMSE).
- Familiarity with version control using Git.

## Preferred Skills
- Experience with Natural Language Processing (NLP), LLMs, RAG architectures, or Computer Vision.
- Knowledge of cloud data services (AWS SageMaker, Google Cloud Vertex AI).
