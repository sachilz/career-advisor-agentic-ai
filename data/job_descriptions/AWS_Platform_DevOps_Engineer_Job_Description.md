# AWS Platform / DevOps Engineer Job Description

## Location

-   Gurgaon

## Employment Type

-   Full-Time

## Experience

-   2--3 Years

## Job Summary

We are seeking a motivated AWS Platform / DevOps Engineer with hands-on
experience in AWS cloud infrastructure, CI/CD, and automation. The role
focuses on managing cloud infrastructure, supporting deployments,
automating operations, and ensuring platform reliability and security.

## Key Responsibilities

-   Manage and maintain AWS cloud infrastructure.
-   Deploy and manage containerized applications using Amazon ECS.
-   Build, maintain, and troubleshoot CI/CD pipelines using Jenkins and
    AWS CodePipeline.
-   Provision infrastructure using Terraform and/or AWS CloudFormation.
-   Configure AWS networking (VPC, Transit Gateway, Security Groups,
    Route Tables, Load Balancers).
-   Manage Amazon S3, CloudFront, Amazon RDS, and AWS Backup.
-   Automate operational tasks using Python and Shell scripting.
-   Monitor infrastructure, troubleshoot issues, and support production
    deployments.
-   Collaborate with development and security teams.
-   Maintain technical documentation and runbooks.
-   Implement AWS security best practices and IAM access controls.
