# Network Engineer Job Description

## Responsibilities

-   Handle tickets and incidents using **ServiceNow**.
-   Lead technical incident calls as a Subject Matter Expert (SME).
-   Troubleshoot and provide break-fix support for technical issues.
-   Perform root cause analysis (RCA) for incidents.
-   Define and improve operational processes while ensuring compliance.
-   Resolve issues within SLA-driven environments.
-   Mentor and train team members as an SME.
-   Perform testing and audits when required.
-   Improve customer and employee satisfaction.
-   Work within a global **Follow the Sun** support model.

## Technology Knowledge

-   Cisco Firepower / FMC / ASA
-   Cisco VPN, GRE, MPLS, WAN
-   Cisco ISE
-   Cisco Meraki
-   F5 Load Balancer
-   Cisco SD-WAN (preferred)

## Qualifications

-   Minimum **5+ years** of Network Engineer experience supporting
    global network infrastructures.
-   Experience working in a **Follow the Sun** global support model.
-   Cisco **CCNP** and other networking certifications.
-   Expert knowledge of troubleshooting LAN/WAN architectures and IP
    services.
-   Expert knowledge of VPN (IPSEC/SSL), GRE, Load Balancers, and
    security technologies.
-   Extensive hands-on experience with:
    -   Cisco Firepower
    -   Cisco ASA
    -   Cisco ASR / ISR
    -   Cisco ISE
    -   VPN and GRE technologies
    -   Firewall policies
    -   F5 Load Balancers
-   Cisco SD-WAN experience is a plus.
