# Comprehensive Guide to AWS Certifications for Beginners & Professionals

## Overview of AWS Certification Path
Amazon Web Services (AWS) offers widely recognized certifications for IT professionals, undergraduates, and cloud engineers.

### 1. Foundational Level: AWS Certified Cloud Practitioner (CLF-C02)
- **Target Audience**: Beginners, IT students, fresh graduates, or non-technical professionals entering cloud computing.
- **Prerequisites**: Basic IT knowledge; no prior cloud experience required.
- **Key Exam Domains**:
  - Cloud Concepts & Value Proposition (24%)
  - Security & Compliance Model (30%)
  - Cloud Technology & Core AWS Services (34%)
  - Billing, Pricing & Support Models (12%)
- **Recommended Preparation**: 2-4 weeks of study using official AWS Skill Builder and practice exams.

### 2. Associate Level Certifications
- **AWS Certified Solutions Architect – Associate (SAA-C03)**:
  - Focuses on designing resilient, high-performing, secure, and cost-optimized architectures.
  - Covers VPC networking, EC2, S3, IAM, RDS, DynamoDB, Lambda, Auto Scaling, and Load Balancers.
- **AWS Certified Developer – Associate (DVA-C02)**:
  - Focuses on developing, deploying, and debugging cloud-based applications using AWS SDKs, Serverless (Lambda, API Gateway, DynamoDB), and CI/CD tools.
- **AWS Certified SysOps Administrator – Associate (SOA-C02)**:
  - Focuses on deployment, management, security, and operations on AWS systems.

### 3. Recommended Path for IT Students in Sri Lanka
Start with **AWS Certified Cloud Practitioner** to build core cloud vocabulary, then immediately progress to **AWS Certified Solutions Architect - Associate** for practical, industry-demanded job skills in DevOps, Cloud Engineering, and Backend Software Engineering.
