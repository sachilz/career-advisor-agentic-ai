# Technical Resume Building Guidelines for IT Graduates

## Key Sections for an Effective Tech Resume

### 1. Header & Contact Information
- Full Name, Professional Title (e.g., "Aspiring DevOps Engineer | Final Year IT Student").
- Email address, LinkedIn URL, GitHub profile link, portfolio site link.

### 2. Technical Skills Matrix
Group skills clearly:
- **Languages**: Python, Java, JavaScript, Bash, SQL.
- **Frameworks & Libraries**: React.js, FastAPI, Node.js, Scikit-Learn.
- **Cloud & DevOps**: AWS (EC2, S3, IAM), Docker, Kubernetes, GitHub Actions, Terraform.
- **Databases & Tools**: PostgreSQL, MongoDB, Git, Postman, Linux.

### 3. Projects (Crucial for Graduates)
- Highlight 2-3 significant projects with:
  - Concise bullet points summarizing technologies used and architecture.
  - Links to live demos or public GitHub repositories.
  - Action verbs (e.g., "Implemented microservices architecture...", "Containerized application using Docker...").

### 4. Education & Certifications
- Degree title, University name, expected graduation year, GPA (if strong).
- Industry certifications: AWS Certified Cloud Practitioner, CompTIA Security+, etc.
