# Sri Lanka Tech Industry Career & Salary Overview

## Industry Landscape in Sri Lanka
Sri Lanka's IT-BPM sector is a vibrant export domain with companies specializing in custom software development, cloud infrastructure, AI solutions, data engineering, and fintech. Major IT hubs are located around Colombo, Kandy, and Jaffna.

## Typical Career Progression & Roles

### 1. Intern / Trainee Software Engineer
- **Experience**: Undergraduate final year / Internship (3-6 months).
- **Core Focus**: Learning codebase standards, bug fixing, unit testing, working under senior developer supervision.

### 2. Associate Software Engineer / Associate DevOps Engineer
- **Experience**: Fresh graduate (0 - 1.5 years).
- **Core Focus**: Delivering features, writing clean REST APIs, pipeline maintenance, active participant in Scrum.

### 3. Software Engineer / DevOps Engineer
- **Experience**: 2 - 4 years.
- **Core Focus**: Module ownership, system design contributions, mentoring associate engineers, optimizing cloud infra.

### 4. Senior Engineer / Technical Lead / Solutions Architect
- **Experience**: 5+ years.
- **Core Focus**: High-level architecture, team leading, client communication, security and compliance.
